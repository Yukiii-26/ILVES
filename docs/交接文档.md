## 2. 环境事实（已验证，不要重复踩坑）

- **Unity 6.3 LTS `6000.3.27f1`**，装在 `D:\Unity\Editors\6000.3.27f1`；只有 Windows Build Support（Mono + IL2CPP）。
- **许可**：Unity Personal，离线 entitlement；**2026-11-24 前需联网刷新一次**。批处理每次会打许可告警，但退出码 0、构建正常。
- **Git 2.56 + Git LFS 3.8**；`gh` 已登录账号 `Yukiii-26`，但**不在 PATH**（实体 `D:\Tools\gh\bin\gh.exe`）。
- **推送走 SSH**（`git@github.com:Yukiii-26/ILVES.git`），因为 `~/.gitconfig` 里给 github.com 写死的代理 `127.0.0.1:7897` 是死的；**不要改用户的全局 git 配置**。
- 显示器 **2560×1440 @125% 缩放**；游戏窗口 1280×720 时文字偏小，设置里有三档字号。
- **截图只截游戏窗口**：用 `tools/shot_window.py`（Pillow + Win32：EnumWindows 按 pid 找窗口 → GetClientRect + ClientToScreen → ImageGrab 客户区；进程先 SetProcessDpiAwareness(2)，否则 125% 缩放下会截错区域）。
  **绝不要整屏截图**——上一次整屏截图把用户桌面发到了 GitHub，已删库重建。
- **截图前必须确认窗口在最上层**：`shot_window.py` 会用 `WindowFromPoint` 在 7 个采样点核对，若被别的窗口（浏览器、资源管理器）盖住就先提到最前重试 6 次，仍不行就**报错退出、不截图**。
  本轮就因为浏览器盖住游戏窗口，抓到过一张 GitHub 页面——这个守卫就是为此加的，**不要绕过它**。用户在用电脑时尤其注意。
- **跑 Unity 批处理必须用 `Start-Process -Wait`**：PowerShell **后台作业**里 `& Unity.exe` 不会等进程退出（会得到空 `$LASTEXITCODE`，并在日志生成之前就去读日志）。统一用 `tools/ilves_unity.ps1 -Method <方法> -Log <日志>`，它内部就是 `Start-Process -Wait -PassThru` 并把 `[ILVES-*]` 行抓出来。
- PowerShell 脚本参数**不要叫 `-Args`**：`$Args` 是自动变量，会导致传入值为空（本轮踩过，表现为"游戏参数神秘失效"）。

### 3.1 主界面美术与图标（2026-10-30 新增）

**素材怎么来的**：负责人把三张图放进 `D:\DeepSeek_工作区\GitHub-3\猞猁小队基础设定集`（只读），由 `tools/gen_art_assets.py` 一遍生成工程用的版本：

| 源素材（只读） | 工程内产物 | 处理 |
|---|---|---|
| 标题艺术字.png 1672×940（纯黑底 + 橄榄绿字） | `Resources/art/title-logo.png` 1363×349 RGBA | luma>8 裁内容框 + 8px padding；`alpha = clamp((luma-3)/19, 0, 1)` 把纯黑键成全透明；RGB 不动 |
| 主页背景图.jpg 1671×941 | `Resources/art/title-bg.jpg` 1671×941 | 重编码 JPEG q88 / 4:4:4（276 KB；暗调渐变怕彩度子采样出色带） |
| 图标.png 1254×1254 | `Art/icon.png` 1024×1024 RGBA | LANCZOS 缩放，不裁边、不加圆角 |
| 上面三张原图 | `docs/设定集/assets/` 英文文件名 | 逐字节拷贝归档（SSOT 素材区） |

**导入参数别手改**：`Assets/Editor/ArtImportSettings.cs` 是个 `AssetPostprocessor`，强制三张图 = Default 贴图 / 关 mipmap / `npotScale=None` / Clamp / 字标**不压缩**（压缩会把 alpha 柔边压出一圈灰边）/ 背景 CompressedHQ / 图标不压缩。`DemoBuild.ConfigurePlayer()` 里的 `EnsureArtImported()` 每次构建前再 `ImportAsset(ForceUpdate)` 一遍，所以**即使有人手滑改了 Inspector 也会被拨回来**；ContentCheck 也会校验这几项。

**主界面版式**（`DemoBootstrap.DrawTitle()`）：内容整列靠左（`TitleColX=92`），字标宽 `TitleLogoW=520`、高度按贴图实测宽高比算，按钮 320×42、间距 48。背景 `DrawTitleBackdrop()` 做三件事：`ScaleAndCrop` 铺满 → 整体压 34% 黑 → 叠一道**运行时生成的 256×1 黑色横向渐变**（`MakeLeftScrim()`，左侧 alpha 0.94，到 0.74W 处收到 0）。**两张图任一缺失都会自动降级**（退回纯文字标题 / 纯色底），不会白屏——删图不会崩，只会丑。

**图标**：`DemoBuild.ConfigureIcons()` 用 `PlayerSettings.GetIconSizes(NamedBuildTarget.X, IconKind.Application)` 取槽位数组，把同一张 1024 母版填满所有槽位（Standalone 8 个 + Android 6 个 = 14）。实测 48px / 32px 仍能认出「ILVES 字标 + 卧姿狙击手剪影」，16px 是一团暗橄榄（可接受）。

**已知取舍**：Android 只设了 legacy Application 图标（`IconKind.Adaptive` 的 `Kind=1` 槽位留空）——自适应图标需要单独的前景安全区素材，硬套满幅图会被启动器裁掉一圈；当前让 Unity 走 legacy 路径。

**换图流程**：新图放进只读素材目录 → `python tools/gen_art_assets.py` → `ContentCheck`（会报尺寸/导入参数问题）→ 构建 + 截图验收。

### 3.2 音乐 / 基本提示 / 声明 / 设置 / 存档（v0.3.0 新增）

**音乐**：三首 FLAC 放 `Assets/Resources/music/`，`DemoBootstrap.SetupMusic()` 加载、`UpdateMusic()` 每帧算「当前该放哪首」（只在变化时切歌，不会每帧重启音频）：

| 文件 | 曲目 / 作者 | 时长 | 用在哪 |
|---|---|---|---|
| title.flac | Ripples / Sean Oban | 2:12 | 主界面 + 设置 / 存档 / 声明 / 基本提示（一切非游玩界面） |
| story-1.flac | Onthou / Ever So Blue | 2:08 | 游玩界面（章节序号为**偶**：序章、第二章） |
| story-2.flac | Veloma / Fabrizio Paterlini | 2:48 | 游玩界面（章节序号为**奇**：第一章） |

- Unity 6 **能直接导入 FLAC**（实测 AudioClip 时长正确），所以工程里留 FLAC 母版、不用外部转码器；构建时按 `AudioImportSettings`（Streaming / Vorbis q0.7 / PreserveSampleRate）重新编码，130 MB 里音乐约占 10 MB。
- 场景是构建时现建的，里面**没有 AudioListener** → `SetupMusic()` 会自己补一个，**别删这段**（删了就是全程静音且不报任何错）。
- 音量四档在 `MusicLevels`（0 / 0.28 / 0.55 / 0.85），存 `PlayerPrefs` 的 `ilves.musiclevel`，默认「中」。
- `-audiocheck` 是播放自检：起游戏等 2.6 s，把 `isPlaying / audioTime / listener` 打进 `Player.log` 再退出。**只信 isPlaying 会被骗**（没有 listener 时它照样 true），必须看到 audioTime 在涨。

**基本提示 + 声明**（负责人 2026-10-30 明确要求，属于合规内容，**不要删改措辞**）：
- `Phase.Notice` 是启动默认界面（带 `-skipnotice` 或任何 QA 参数会跳过，见 §4）：四条 + 项目 GitHub 地址 + 「我已知悉」「打开项目主页」。
- `Phase.Declaration` 是「声明」页，五个小节可滚动（`DrawScrolledText`）；入口在主界面和 设置→其它 两处。
- 文案集中在 `DemoBootstrap.DeclarationText` 与 `DrawNotice()`；**换曲目必须同步改声明里的曲目表**。
- `ContentCheck.CheckPolicyText()` 守住这几条：必须有「均为虚构 / 完全免费 / 不良导向 / 版权归原作者」、必须有 GitHub 地址、且主界面描述里**不许再出现**「你是指挥官」。

**设置界面（两栏）**：左栏是栏目（画面 / 声音 / 其它），右栏是内容，靠 `SettingsTab` + `SettingsDisplay / SettingsAudio / SettingsAbout` 分发，选项行统一走 `ChoiceRow()`。

**存档 3 → 6 档**：全部逻辑由 `const int SlotCount = 6` 与 `SlotNames` 驱动（`RefreshSlotMeta` / `HasAnySave` / `LatestSavePath` / `DrawSlots` 都按 `SlotCount` 循环）。界面是**单列 6 行**（每行 68 px）——再加档位就得改版式（一屏放不下，要加滚动）。

### 调试参数（方便验证界面）

| 参数 | 作用 |
|---|---|
| `-node=n12` / `-node=m03` / `-node=p05` | 直接跳到某章某节点（n=第一章，m=第二章，p=序章） |
| `-member=igor` | 进第一章正文并直接打开该队员档案弹窗（本轮新增，三档字号验收用） |
| `-phase=notice\|declaration\|settings\|briefing\|pause\|slots` | 直接打开某页（notice = 基本提示，declaration = 声明） |
| `-skipnotice` | 跳过启动时的「基本提示」，直接进主界面（截图 / 无头跑流程用；`-typing` 也会自动跳过） |
| `-audiocheck` | 音乐播放自检：等 2.6 s 把 isPlaying / audioTime / listener 写进 Player.log 后退出（返回码 0/1，看 audioTime 有没有涨） |
| `-font=0\|1\|2` | 界面字号 小/标准/大 |
| `-res=0\|1\|2` | 窗口分辨率（强制窗口模式，不写设置） |

## 5. 加一章内容（唯一的剧情入口）

1. 新建 `Assets/Resources/content/chapter03.json`；
2. 在 `DemoBootstrap.ChapterFiles` 数组末尾加 `"chapter03.json"`；

4. 构建，用 `-node=...` 抽查几个节点截图。

### JSON 结构

```json
{"chapterId":"ch03","title":"第三章","subtitle":"雨与沼泽","clockStart":"04:20",
 "briefing":"简报正文，\n\n可分段",
 "objectives":["目标一","目标二"],
 "start":"r01",
 "nodes":[
  {"id":"r01","scene":"林线 · 05:40","speaker":"瓦西里","text":"……",
   "choices":[{"text":"选项","next":"r02","effects":["exposure+5","time+15","flag.x=true","member.igor=受伤"],"note":"谨慎"}],
   "next":"r02"},
  {"id":"r02","text":"……","end":true}
 ]}
```

**效果 DSL**：`exposure±N`（0–100）、`time±N`（分钟）、`intel±N`（0–6）、`trust±N`（-5–5）、`flag.名字=true/false`、`member.队员id=状态文字`。
选项可选 `visibleIf:["flag.a","!flag.b"]`。

**写作约定（用户确认过）**
- 单章 **15–30 分钟**（按「正文+选项文字」约 300 字/分钟估）。现在的基准：序章 4400 字、正章 7200–8200 字。
- **强连续**：旗标跨章。写新章前先读 `docs/剧情旗标登记.md`，**不要重复发明语义相近的旗标**。
- **俄语术语首次出现必须括号解释**，如 `«Штаб»（指挥部）`；第二次出现不再解释。
- **不追爽感，奖励“克制”**；每个决策都要有代价。
- 每个节点正文 **150–320 字**（硬上限 420，ContentCheck 会警告）、**2–5 段**；单节点选项 **2–4 个**（界面只画 4 个）。
- `note` **只能是「谨慎」「激进」「欺骗」「拖延」**四选一——复盘页按这四个词统计，ContentCheck 会报错。
- `member.X` 的状态值只用：待命 / 受伤 / 兴奋 / 专注 / 沉默 / 开火 / 射击 / 驾驶 / 救治 / 紧张 / 焦虑 / 失联 / 离队。
- `visibleIf` 写成 `"flag.xxx"`（**必须带前缀**），且该旗标必须在**任意章节**的 `effects` 里被 `flag.xxx=true` 设置过，否则 ContentCheck 报错。
- `clockStart` 是本章开场钟点（`"HH:MM"`），侧栏「时间」= clockStart + 本章累计 `time+`。**新章的 scene 钟点要和它自洽**（同一路径累计时间对得上，±5 分钟内）。
- 正文会自动分页（一页一屏，点击翻页），所以不需要为了排版硬拆节点；但 150–320 字仍是节奏上的合适长度。
- 写完先跑 `tools/ilves_audit.py`（秒级，不用 Unity）自检，再让 Lead 跑 ContentCheck。

11. **文字绘制铁律（不要绕过）**：界面里所有文字必须走 `Label()` 或 `LabelClipH()`——它们会先用 `GUIStyle.CalcHeight()` 量出实际需要的高度、矩形不够就自动加高（居中样式上下对称加高），所以任何分辨率、任何字号都不会把文字下沿切掉（历史 bug 代号“遁地”）。
   - 需要“只在横向裁切”的文字（如人物栏职位不许压到状态列）用 `LabelClipH()`：宽度照裁，高度自动加高。
   - 需要滚动的长文（队员档案弹窗）用 `DrawScrolledText()`：它把可视高度和滚动量都吸附到**整行**，所以不会出现半行被切。
   - **滚动内容高度要用 `GetCursorPixelPosition` 量“最后一行”，再和 `MeasureText` 取最大值**：只按行数比估算会少算几行，导致 `maxScroll` 偏小、滚到底也看不全（档案弹窗就踩过这个坑）。见 `DrawScrolledText` 里 `trueH` 的算法。
   - **度量要用 `MeasureText()`，不要直接用 `CalcHeight()`**：实测 `CalcHeight("国")` 报 36.41px，而真实行距只有 **30.41px**（22px 正文），每行高估约 6px。`MeasureText` = CalcHeight 的行数比例 × 真实行距（用 `GetCursorPixelPosition` 量三行取差），分页/滚动判断都用它。用 CalcHeight 直接分页会每页少塞约 1.5 行（“文字框太空”）。
   - 正文分页按**句子**装页（`SplitSentences`）：页尾能塞进一个完整句子就塞，绝不把一句话劈到两页；单句本身超一页才按字符二分。
   - 直接写 `GUI.Label` 会被 ContentCheck 的源码 lint 判为 error（只有三个带 `[text-primitive]` 标记的原语例外）。新增界面时照这个模式写。
