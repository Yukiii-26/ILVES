## 2. 环境事实（已验证，不要重复踩坑）

- **Unity 6.3 LTS `6000.3.27f1`**，装在 `D:\Unity\Editors\6000.3.27f1`；只有 Windows Build Support（Mono + IL2CPP）。
- **许可**：Unity Personal，离线 entitlement；**2026-11-24 前需联网刷新一次**。批处理每次会打许可告警，但退出码 0、构建正常。
- **Git 2.56 + Git LFS 3.8**；`gh` 已登录账号 `Yukiii-26`，但**不在 PATH**（实体 `D:\Tools\gh\bin\gh.exe`）。
- **推送走 SSH**（`git@github.com:Yukiii-26/ILVES.git`），因为 `~/.gitconfig` 里给 github.com 写死的代理 `127.0.0.1:7897` 是死的；**不要改用户的全局 git 配置**。
- 显示器 **2560×1440 @125% 缩放**；游戏窗口 1280×720 时文字偏小，已在设置里加三档字号。
- **截图规则：只截游戏窗口**（Win32 `GetClientRect + ClientToScreen` + `ImageGrab`），绝不整屏——上一次整屏截图把用户桌面发到了 GitHub，已删库重建。

## 4. 运行 / 构建 / 校验（照抄即可）

```powershell
# 运行
D:\UnityProjects\ILVES\Builds\Windows\Ilves.exe

# 内容校验（无头，几十秒）
$unity = "D:\Unity\Editors\6000.3.27f1\Editor\Unity.exe"
& $unity -batchmode -projectPath "D:\UnityProjects\ILVES" `
  -executeMethod Ilves.EditorTools.ContentCheck.Run -logFile "D:\UnityProjects\ILVES\Logs\check.log"
# 期望最后一行：[ILVES-CHECK] PASS

# 打 Windows 包
& $unity -batchmode -projectPath "D:\UnityProjects\ILVES" `
  -executeMethod Ilves.EditorTools.DemoBuild.BuildDemo -logFile "D:\UnityProjects\ILVES\Logs\build.log"
# 期望：[ILVES-BUILD] result=Succeeded ... output=D:/UnityProjects/ILVES/Builds/Windows/Ilves.exe
```

### 调试参数（方便验证界面）

| 参数 | 作用 |
|---|---|
| `-node=n12` / `-node=m03` / `-node=p05` | 直接跳到某章某节点（n=第一章，m=第二章，p=序章） |
| `-phase=settings\|briefing\|pause\|slots` | 直接打开某页 |
| `-font=0\|1\|2` | 界面字号 小/标准/大 |
| `-res=0\|1\|2` | 窗口分辨率（强制窗口模式，不写设置） |
| `-typing` | 冻结打字机，检查提示行等静态文字 |
| `-debrief` | 一路选第一项快进到复盘 |
| `-autoplay-demo` | 无头跑完三章并打印结果（返回码 0/1） |
| `-savetest` | 存档写盘→清内存→读盘自检 |

## 5. 加一章内容（唯一的剧情入口）

1. 新建 `Assets/Resources/content/chapter03.json`；
2. 在 `DemoBootstrap.ChapterFiles` 数组末尾加 `"chapter03.json"`；
3. 跑 ContentCheck（会报缺失跳转/不可达节点/死循环）；
4. 构建，用 `-node=...` 抽查几个节点截图。

### JSON 结构

```json
{"chapterId":"ch03","title":"第三章","subtitle":"雨与沼泽",
 "briefing":"简报正文，\n\n可分段",
 "objectives":["目标一","目标二"],
 "start":"r01",
 "nodes":[
  {"id":"r01","scene":"林线 · 05:40","speaker":"瓦西里","text":"……",
   "choices":[{"text":"选项","next":"r02","effects":["exposure+5","time+15","flag.x=true","member.igor=受伤"],"note":"谨慎"}],
   "next":"r02"},
  {"id":"r02","text":"……","end":true}
 ]}
```

**效果 DSL**：`exposure±N`（0–100）、`time±N`（分钟）、`intel±N`（0–6）、`trust±N`（-5–5）、`flag.名字=true/false`、`member.队员id=状态文字`。
选项可选 `visibleIf:["flag.a","!flag.b"]`。

**写作约定**（用户确认过）：单章 15–30 分钟；强连续（旗标跨章）；**俄语术语首次出现必须括号解释**，如 «Штаб»（指挥部）；不追爽感，奖励“克制”。

## 7. 已知问题 / 待办

1. **Android（阻断）**：模块已手工装进 `PlaybackEngines\AndroidPlayer`（SDK/NDK/JDK 齐全），但 Unity 构建报 `Failed to update Android SDK`（要求 Hub 正规安装的版本元数据）。
   - 解决路径：让用户在 **Unity Hub → Installs → 6000.3.27f1 → 齿轮 → Add modules** 安装 *Android Build Support（含 SDK & NDK Tools、OpenJDK）*，然后执行 `DemoBuild.BuildAndroidDemo` 即可出 APK。
   - APK 参数已定：ARM64 / IL2CPP / 横屏 / `com.understory.ilves` / bundleVersionCode 2。
2. 复盘页的“目标/友军”判断只统计了第一章的旗标，第二章的旗标只加了几行，可继续补。
3. 没有自动存档列表界面；`save_auto.json` 只被“继续游戏”使用。
4. 无音效、无美术资源（IMGUI 原型，这是刻意选择：先把文字与决策跑通）。
5. 内置字体 16MB，Windows 包因此 ~47MB；如需瘦身可换子集字体。

## 8. 工作约定（必须遵守）

1. **设定集是 SSOT**：改世界/人物先改 `docs/设定集/猞猁小队-工作设定集.md`，再改剧情。
2. **每次改完跑 ContentCheck**；构建后**实际启动并截图**确认，不要只看编译通过。
3. **截图只截游戏窗口**（见 §2），并检查画面里没有桌面/个人信息。
4. 提交信息用中文，前缀 `feat:` / `fix:` / `docs:` / `chore:`；改完即推 `main`。
5. 版本号：`PlayerSettings.bundleVersion` + git tag + Release 三处保持一致；用户要求“版本不变”时不要擅自升版。
6. 不要改用户的全局 git 配置、不要动 `D:\DeepSeek_工作区\GitHub-3\猞猁小队基础设定集` 里的原始素材。
