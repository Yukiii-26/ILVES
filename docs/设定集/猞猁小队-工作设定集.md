## 1. 世界与作战区域

### 1.1 地理

任务区域不是地图上的公路与城镇，而是**树冠蔽天、腐叶吸水、大片留白的绿色沉默**：卡累利阿方向的泰加林、无路沼泽与寒带密林〔原文〕。

〔整理〕可据此定下三类地表，直接对应关卡与移动系统：

1. **泰加林／密林**——树冠遮挡视线与卫星链路，通讯与无人机受限，是这支队伍的"主场"与"盲区"。
2. **无路沼泽**——负重即陷落，机动被体能与装备重量直接惩罚；绕行代价是时间。
3. **寒带开阔地／雪原**——远景暴露、热像与狙击射界打开，但风、雪、低温同时惩罚双方。

### 1.2 环境即敌人

"在这片林子里，最先要打败的从来不是人，是冷、是湿、是虫、是距离。"〔原文〕

〔推断〕这句话应升级为**第一设计原则**：任何关卡的失败条件里，环境都应有独立的一票；玩家的主要压力来源是"时间 + 体温 + 痕迹"，而不是血量。

### 1.3 战争状态与时间线

〔待定〕原文未给出时代背景、交战双方、战争性质。当前可确定的是"现代俄军装备体系 + 边境低烈度冲突"的质感。建议后续在以下三种基调中选一：

- A. 现代、模糊的边境冲突（最贴原文，政治敏感度最低）
- B. 近未来（可容纳更多电子战／无人机反制玩法）
- C. 架空国家与架空战争（最大创作自由，最易过审与上架）

## 2. 组织与建制

| 层级 | 内容 |
|---|---|
| 番号 | ООСпН «Илвес»——独立（отдельная）特种用途小组 |
| 规模 | 定额 9 人；9 人**全部有名有姓有岗位**，没有"背景板士兵" |
| 指挥链 | 组长（瓦西里）→ 副队长（伊戈尔）→ 各岗位；组长失能由副队长接管〔原文〕 |
| 上级关系 | 与后方指挥存在**长期路线分歧**〔原文〕；组长擅长"与上级吵得动" |
| 自主性 | 具备侦察、标记、打击、狙击、通信、突击、阻滞全套能力，可脱离主力在林区独立活动数日〔原文〕 |
| 军衔体系 | 虚拟俄军士兵/士官体系：中士、下士（младший сержант）、准尉、上等兵、列兵 |
| 真实性声明 | 番号、地名、人名均为虚构〔原文〕 |

**9 个岗位即 9 个不可替代的功能位**〔整理〕：决策／尖兵与火力引导／狙击／观察与救护／通信与电子战／突击／工兵／机动驾驶／压制火力。任何一人缺位，系统就出现一个缺口——这是玩法设计的天然支点。

## 3. 队名与徽章（视觉规范）

### 3.1 名字

- **卡累利阿地方语**：猞猁（队名来源）
- **俄语标准写法**：рысь；队内老兵仍习惯这样叫
- **编制名**：ООСпН «Илвес»
- **中文**：猞猁小队
- **英文**（〔推断〕供国际版使用）：**Ilves**（保留原名，音译/原名并置比意译"Lynx"更有辨识度）

### 3.2 徽章构成与含义〔原文〕

| 元素 | 含义 |
|---|---|
| 暗黑底 + 单色橄榄绿线 | 整支队伍的视觉基调：克制、消光、不反光 |
| 猞猁侧脸 | 队伍的精神图腾：盯着、然后一击，不恋战 |
| 一截松枝 + 三颗松果 | 作战地域（泰加林）；三颗松果＝三次深入敌后（与三道抓痕同数） |
| 三道划破内圈的抓痕 | 三次深入敌后 |
| 被划开的内圈 | "从包围里撕开一条路" |

### 3.3 色彩规范〔整理自素材取色〕

| 用途 | 色值 | 说明 |
|---|---|---|
| 底色／背景 | #050504（备选纯黑 #000000） | 近黑，不用纯黑以留印刷与刺绣余量 |
| 主色／线条 | #767954 | 橄榄绿，主视觉唯一亮色 |
| 暗部／阴影线 | #4E5037 | 层次与压暗，不超过主色面积 |
| 刺绣版 | 以 #4C4B37 系线色为主 | 不做渐变、不做高光，靠针脚密度表现明暗 |

**使用规则**〔推断，美术执行时用〕

- 单色优先：任何场合都不得给徽章加第二种彩色（红/金只允许出现在独立的信息标识上，不进入徽章）。
- 徽章不得加描边光晕、不得投影、不得做渐变或金属质感。
- 最小尺寸：屏幕 48 px／印刷 12 mm，低于此尺寸只保留"猞猁头 + 三爪"。
- 军用场景中徽章应做低可视度处理（单色暗橄榄、无高光），符合"外观克制、部件消光、不反光"的设定态度。

### 3.4 素材实测核对（2026-10-25，AI 放大逐项点数）

用图像裁切逐项核对文字设定与三版队徽，结论如下——**文字设定为准；其中一处（松果数量）需用户在"改文字"与"改图"之间拍板**：

| 元素 | 文字设定 | 图上实际 | 判定 |
|---|---|---|---|
| 松果数量 | 两颗 | **三颗**（枝端一颗小、枝中一颗、右侧一颗大） | ✅ **已定案（2026-10-25）**：负责人决定以图为准＝三颗，文字已同步 |
| 抓痕 | 三道，**划破内圈** | 三道，确实**划穿内圈**；外圈保持完整 | ✅ 一致（提案 §6.1 第 9 条称"划破外圈"系误判，以本节实测为准） |
| 破圈含义 | "从包围里撕开一条路" | 内圈在三处抓痕位置被擦断，语义成立 | ✅ 一致 |
| 松枝 | 一截松枝 | 松枝自左上斜切入图，枝梢**越过内圈** | ✅ 基本一致（若做 title lockup，注意枝梢与抓痕都会切断内圈，不要当成印刷错误） |

**定案**：三颗。（三颗＝三次深入敌后，与三道抓痕同数，叙事更整齐；美术资产不动。）

## 4. 猞猁准则（行为信条 → 规则接口）

### 4.1 原文信条

> 潜伏优先、一击脱离、不追不恋。交火不是目的，而是失败之后的补救。

来源故事：冬季任务中，老队员在雪原上远远看见一只猞猁——它盯着他们看了很久，咬了一口狍子，转身就走，从不恋战。回来后这句话被写进队里的准则。〔原文〕

### 4.2 〔推断〕可执行的规则转译

| 信条 | 机制化建议 |
|---|---|
| 潜伏优先 | 未被发现时情报与射界优势最大；暴露度是核心资源，会被噪音、灯光、尸体、脚印、无线电累积 |
| 一击脱离 | 每次交火后都有一个"脱离窗口"，超时敌方增援与追击强度上升 |
| 不追不恋 | 追击敌人有收益诱惑，但会消耗时间/暴露度；完成任务后停留越久，撤离越难 |
| 交火是失败后的补救 | 击杀不计分或低分，隐蔽完成任务给最高评价；暴露即降级 |

## 6. 九人详档

### 6.1 瓦西里 Василий｜组长

- **代号**：«Хозяин»（"当家的"，队员私下叫）｜**军衔**：中士（сержант）｜**年龄／服役**：34 岁，12 年，特种部队 8 年
- **职责**：战术决策、情报研判、后方指挥链路对接、任务权限、统筹进退；组长失能时由副队长接管。
- **主武器**：АК‑105 短管突击步枪｜1‑6× 低倍可变瞄、折叠前握把、IR 激光（夜视下用）、快拆消音器
- **副武器**：ПЯ «Грач»（9×19），快拔枪套
- **随身**：加密战术平板、纸质地图套装、罗盘、任务档案、单兵电台（通信备份）、红/绿信号烟
- **技能**：路线规划、任务取舍、与上级"吵得动"、信息不全时做决定
- **性格**：沉默、稳，话少但每句都算数；不抽烟不喝酒，夜里看地图看到很晚
- **弱点**：**过度保守**。上一次任务因绕沼泽晚了四小时，目标转移；他至今认为那是对的，但一直没睡好
- **关系**：压得住基里尔与帕维尔；压不住伊戈尔的野心；与后方指挥有长期路线分歧
- **冲突钩子**：当"完成任务"和"带人回去"冲突时，他选哪个？
- **玩法接口**〔推断〕：**玩家就是瓦西里**。他的"保守"应体现为系统给玩家的默认倾向——任务简报里更倾向于给出"稳妥但慢"的路线建议，玩家的激进选择会付出额外代价。

### 6.2 伊戈尔 Игорь｜副队长／尖兵／火力引导

- **代号**：«Первый»（"第一个"，因为他总想走在最前）｜**军衔**：下士（младший сержант）｜**年龄／服役**：29 岁，8 年，特种部队 4 年
- **职责**：前出尖兵、开路、侦察行进路线、第一时间接敌预警；副队长，瓦西里失能时接管指挥；目标坐标测算、激光照射、引导炮兵/航空
- **主武器**：АК‑105｜1‑4× 全息倍率瞄、IR 激光、消音器；不追求远距离交战，优先自保
- **副武器**：ПЯ «Грач»
- **随身**：便携激光目标照射器（ЛПР‑2 类，与步枪 IR 激光区分）、弹道计算器、卫星定位终端、气象传感器、微型穿越侦察无人机、目标标记反光板
- **技能**：地形记忆、无人机侦察、火力引导（"引导"从通信员手里接过来，因为他最清楚目标在哪）
- **性格**：外向、爱笑、爱抢第一步；对"第一"有执念
- **弱点**：好胜冒进；树冠下一旦无人机失联，判断会变粗糙
- **关系**：和谢苗长期争"谁管链路"；瓦西里知道他有野心，仍指定他做副队长
- **冲突钩子**：他带来一个"可以打"的目标，但瓦西里认为这是陷阱
- **玩法接口**〔推断〕：**火力引导**是他的专属动词——玩家把"打"的决策交给他，收益是远程精确打击，风险是他会把小队带向暴露。

### 6.3 罗曼 Роман｜狙击手

- **代号**：«Тихий»（"安静的人"）｜**军衔**：准尉（прапорщик）｜**年龄／服役**：38 岁，16 年，狙击教龄 6 年
- **职责**：远距离警戒、精确狙杀高价值目标、远距离阻滞追兵、独立前出构建狙击阵地
- **主武器**：СВ‑98 栓动狙击步枪｜3‑18× 高倍镜、折叠两脚架、消音器、柔性贴腮板；7.62×54R 高精度狙击弹
- **副武器**：ПЯ «Грач»
- **随身**：弹道手册、备用瞄镜、狙击伪装网（披罩）、便携测距仪、备用弹药包
- **技能**：独立潜伏三天不挪窝、一枪一评估、判断"什么目标值得开枪"
- **武器修正**：消音器只降低定位难度，不是无声；静默狙杀需换亚音速弹，射程与精度下降，他要自己权衡
- **性格**：孤僻、话极少；休息时一个人擦枪、一个人看天
- **弱点**：社交孤立，潜伏久了"进入自己的世界"，需要阿尔乔姆把他叫回来
- **关系**：只和阿尔乔姆有稳定的"工作对话"；对基里尔的咋呼最不耐烦
- **冲突钩子**：高价值目标身边有平民/少年，开不开枪？
- **玩法接口**〔推断〕：**"值得开枪"应成为一个显式判断**——每次狙击前给出目标价值/风险/附带伤害评估，而不是简单命中判定。

### 6.4 阿尔乔姆 Артём｜观察手／战斗救生员

- **代号**：«Док»（"医生"）｜**军衔**：中士（сержант）｜**年龄／服役**：31 岁，9 年，医疗训练 3 年
- **职责**：配合狙击手测风测距、观察警戒、记录目标；兼任小队战斗救生员（CLS）

## 7. 装备与后勤体系

### 7.1 设计原则〔原文〕

- **防护换机动**：全队不插重型陶瓷板，6Б45 只保留软质防破片层——负重每多一公斤，沼泽就多吞一步；防护侧重破片，而不是硬扛步枪弹。
- **口径收敛**：步枪 5.45×39、狙击 7.62×54R、手枪 9×19。补给线越短，深入得越远。
- **消音器=临时件**：行军时收起，接敌前才拧上，因为泰加林的泥水会堵住它。
- **夜视按岗位分级**：热像只在最需要"找人"的几双眼睛里〔推断：罗曼、阿尔乔姆优先；伊戈尔、尼古拉有微光；其余以微光/裸眼为主〕
- **外观克制**：部件消光、不反光，是这支队伍对森林的基本礼貌。

## 9. 玩法接口（v0.2：方向已确认）

> 2026-10-25 负责人确认：**2D、文字为主、章节制、"指挥而非作战"、核心游玩点是博弈**。
> 完整玩法设计见 docs/游戏构想.md（那边是"玩法唯一事实源"）；本节只保留**设定 → 玩法**的接口，供写作与系统设计取用。

### 9.1 玩家扮演什么

玩家＝组长瓦西里。**玩家不扣扳机，玩家做决定**：谁去、走哪条路、打不打、什么时候撤、要不要开机。任务以潜伏、侦察、与友军队伍配合为主；交火是失败后的补救。

### 9.2 一层操作模型：章节 → 节点

不做实时战斗，也不做纯回合战棋。每章＝一个任务，任务被拆成 **15–25 个"决策节点"**（岔路、哨位、脚印、无线电阻断、雪盲、伤员、友军请求……），每个节点让玩家选"怎么做／谁去做／做不做"。

1. **计划层（章首）**：读情报板、看 2D 态势图、分岗位、定路线与撤离点、定交战规则（ROE）。
2. **执行层（节点推进）**：文本 + 地图标记推进，指令以无线电/档案形式下达，队员按自己的性格执行。
3. **复盘层（章末）**：暴露度、耗时、伤员、情报质量、是否遵守 ROE——用"猞猁准则"评分，而不是击杀数。

### 9.3 九人＝九种动词

| 队员 | 玩家可下达的动词 |
|---|---|
| 瓦西里 | 决策、授权、放弃/继续 |
| 伊戈尔 | 前出、引导打击、无人机侦察 |
| 罗曼 | 占领阵地、狙杀、评估目标 |
| 阿尔乔姆 | 观察、救治、稳定情绪 |
| 谢苗 | 静默、开台、干扰、反无人机 |
| 基里尔 | 破门、突入、抓捕、断后 |
| 德米特里 | 布雷、排雷、爆破 |
| 尼古拉 | 驾驶、运输、探路 |
| 帕维尔 | 压制、掩护撤离 |

### 9.4 压力来源（对应"环境即敌人"）

体温／体力／暴露度／通信质量／弹药／时间／队员心理状态。**任何一项归零都不应直接 Game Over，而应触发"裂缝"**——对应原文"九个人，九处裂缝"。

### 9.5 失败与代价

建议不做"读档重来式"惩罚，而做**战役级累积**：伤员需要时间恢复、装备损耗不可即时补充、队长的决策被队员记住（关系值），最终影响结局与队伍存续。
