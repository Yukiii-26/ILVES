### 5.2 `.gitattributes`（1,781 B）

| 规则 | 作用 |
|------|------|
| `* text=auto` | 默认按文本归一（任务要求） |
| `*.cs text diff=csharp eol=lf` | C# 源码 LF + C# 差异高亮（任务要求 `*.cs text diff=csharp`） |
| `*.unity -text` | Unity 场景不做换行转换（任务要求） |
| `*.prefab` / `*.asset` / `*.mat` / `*.anim` / `*.controller` / `*.mask` / `*.meta` 均 `-text` | 其余 Unity YAML 资产同样禁转换，避免字节级差异 |
| `*.shader`、`*.cginc`、`*.hlsl`、`*.compute`、`*.asmdef`、`*.json`、`*.md`、`*.txt`、`*.xml`、`*.yml` 均 `text eol=lf` | 文本类统一 LF |
| **Git LFS**：`*.psd`、`*.png`、`*.jpg`、`*.jpeg`、`*.tga`、`*.exr`、`*.fbx`、`*.wav`、`*.mp3`、`*.mp4` | 均为 `filter=lfs diff=lfs merge=lfs -text`（任务要求的 9 类 + jpeg 补充） |

> 本机 `git-lfs 3.8.0` 已安装且 `~/.gitconfig` 已有全局 `filter.lfs.*`，因此仓库级只需 `.gitattributes` 规则即可生效，无需额外 `git lfs install`。
> 由于本任务禁止 `git init`，**属性实际生效需等 lead 初始化仓库后验证**（建议首次提交前用 `git check-attr` 确认，该命令只能在仓库内运行）。

## 7. 已知现象 / 坑（重要）

1. **许可签名校验告警（每次调用都有，但未阻塞）**
   三份日志各有 3 行许可告警：
   ```text
   [Licensing::Client] Code 10 while verifying Licensing Client signature (process Id: ...)
   [Licensing::Module] LicensingClient has failed validation; ignoring
   [Licensing::Module] Error: Access token is unavailable; failed to update
   ```
   但三次调用均正常退出（0）且设置全部生效 ⇒ 实际走的是本机已激活的 **Unity Personal 离线 entitlement**（`%LOCALAPPDATA%\Unity\licenses\UnityEntitlementLicense.xml`）。
   **风险**：若许可离线有效期（约 2026-11-24）过期，批处理会开始失败。届时先启动 Unity Hub 联网刷新许可即可。
2. **`-createProject` 不套用任何模板** ⇒ `Assets/` 初始为空：**没有初始场景、没有 URP**，`Packages/manifest.json` 只有内置模块 + `com.unity.multiplayer.center`。渲染管线当前为 **Built-in**。
   - 需要初始场景 → 后续任务在 `Assets/Scenes/` 新建；
   - 需要 URP → 联网安装包（本机 `packages.unity.com` 可达，见《环境清单》）。
3. **`.gitkeep` 不会被 Unity 导入**：文件名以点开头，Unity 直接忽略且**不生成 `.gitkeep.meta`**（实测 `Assets/` 下共 13 个 `.meta` = 12 个目录 + 1 个脚本）。它们只在 Git 层起作用，不会污染 Assets 资源清单。
4. **`README.md` 不是本任务产物**：22:21:38 出现于工程根目录（内容为项目说明），非本次脚本所写，本任务**未修改**它。
5. **未做**：`git init`、`git add/commit`、创建 GitHub 仓库、改动 `SchoolScape` 或 `D:\DeepSeek_工作区\GitHub-3` 内任何文件、安装任何模块。
